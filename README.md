# Datasets

The pipeline dynamically routes data loading based on the requested channel architecture. Data consists of `.npz` files generated by the primary Windflow model.

## 1. 3-Channel Dataset (`WindflowUNet3chDataset`)

- Uses a standard flat-directory search for patch files.
- Inputs: `qv_t0` (Moisture), `u_pred` (U-wind prediction), `v_pred` (V-wind prediction).

## 2. 4-Channel Dataset (`WindflowUNet4chDataset`)

- Incorporates vertical cross-level crawling based on a target pressure level (`--target_plev`).
- Inputs: The base 3 channels + 1 dynamically calculated feature channel:
  - `vws` (Vertical Wind Shear): Calculated dynamically by fetching upper and lower sibling pressure levels.
  - `temp` (Temperature): Extracts `temp_t0` from the target level.

# Regression Objectives

The model can be trained to predict two types of error representations:

- `magnitude`: Computes the total Euclidean distance error between predicted and true wind vectors (Outputs 1 channel).
- `component`: Computes the absolute error for U and V components independently (Outputs 2 channels).

# Training the Model

Use `train_unet.py` to train the model. The script includes Weights & Biases (WandB) integration and automatically triggers evaluation upon completion.

## Example: 3-Channel Magnitude Training

```bash
python train_unet.py \
    --channels 3 \
    --regression_type magnitude \
    --target_plev 700 \
    --epochs 30 \
    --batch_size 8 \
    --data_dir /path/to/windflow_outputs
```

## Example: 4-Channel Vertical Wind Shear Training

```bash
python train_unet.py \
    --channels 4 \
    --feature vws \
    --regression_type component \
    --target_plev 700 \
    --epochs 30 \
    --batch_size 8
```

> **Note:** The script features smart-renaming to prevent a 4-channel run from overwriting your 3-channel weights.

# Standalone Evaluation

`evaluate.py` handles post-training inference and statistical analysis (MAE, RMSE, R², and Performance Gain over baseline).

```bash
python evaluate.py \
    --channels 4 \
    --feature vws \
    --regression_type component \
    --target_plev 700 \
    --data_dir /path/to/windflow_outputs \
    --weights_path best_4ch_vws_unet_quality_inspector.pth
```

# Cluster Execution

The repository includes a SLURM job array script designed to run the full matrix of experiments simultaneously.

To dispatch 3ch magnitude, 3ch component, 4ch magnitude, and 4ch component runs in parallel:

```bash
mkdir -p logs  # Ensure logs directory exists
sbatch slurm_scripts/run_experiments.sh
```

Monitor your jobs using:

```bash
squeue -u $USER
```
